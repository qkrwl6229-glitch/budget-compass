# 정산·증빙

> 탐색 지도. 필요 서류 목록은 **개별 사업 정산 매뉴얼이 우선**한다.

## 1. 적격증빙 (세법상 지출증명서류)
사업자로부터 재화·용역을 공급받을 때 받는 증빙:
- 세금계산서(전자세금계산서), 계산서(면세)
- 신용카드매출전표(직불·체크카드 포함), 현금영수증(지출증빙용)

세법상 일정 금액(건당 3만원) 초과 거래에서 적격증빙을 받지 않으면 가산세 대상이 될 수 있다 (법인세법·소득세법) `[조문·금액 현행 확인]`.
보조금 정산에서는 이보다 **엄격한 기준**(보조금 전용카드 사용 의무, 금액과 무관한 적격증빙 요구)을 두는 경우가 많다.

## 2. 지출 유형별 기본 증빙
| 지출 | 기본 증빙 | 추가로 자주 요구되는 것 |
|---|---|---|
| 물품 구매 | 세금계산서 또는 카드전표, 거래명세서 | 견적서(비교견적), 검수조서, 사진 |
| 용역·외주 | 계약서, 세금계산서, 결과물 | 비교견적, 검수조서, 착수·완료계 |
| 인건비 | 근로계약서, 급여대장, 이체확인증 | 원천징수영수증, 4대보험 납부 내역, 참여율 |
| 강사료·자문료 | 지급 내역, 이체확인증, 원천징수 내역 | 강사 이력·위촉 공문, 강의 일지, 신분증 사본 처리는 개인정보 규정 확인 |
| 회의비·식비 | 카드전표 | 회의록(일시·장소·참석자·안건), 참석자 서명 |
| 여비 | 출장명령서, 교통·숙박 증빙 | 출장 결과보고서, 기관 여비규정 |
| 임차료 | 임대차계약서, 세금계산서 | 사용 일지, 사진 |
| 해외 지출 | 인보이스, 송금증 또는 해외 카드전표 | 환율 적용 근거, 번역본 |

## 3. 자주 나오는 불인정 사례 (일반 경향)
- 사업기간 외 지출, 협약 전 계약·결제
- 편성되지 않은 비목 지출, 승인 없는 변경
- 보조금 전용카드·전용계좌 외 결제, 현금 지급
- 개인카드 결제 후 정산(예외 규정 없는 경우)
- 증빙 누락·부실(회의록 없는 회의비, 결과물 없는 용역)
- 사용 제한 업종 결제(유흥·주점 등), 주류 구매
- 매입세액 공제 가능한 사업자의 부가세 집행
- 특수관계자 거래·자기 거래, 분할 결제로 계약 절차 회피
- 사업과 무관한 지출(개인 용도, 다른 사업 겸용)

> 위 목록은 탐색용 경향이다. 답변에는 해당 사업 지침 원문의 불인정 조항을 근거로 쓴다.

## 4. 정산 절차 (국고보조금 일반)
1. 사업 종료 후 실적보고서·정산보고서 작성 (e나라도움 등 시스템 사용)
2. 일정 규모 이상 보조사업은 **외부 회계감사인 등의 정산보고서 검증**이 필요할 수 있음 `[대상 금액 기준은 보조금법·시행령 현행 확인]`
3. 보조금 집행잔액·이자 반납
4. 중요재산은 정산 후에도 사후관리

## 5. 국가R&D 정산
- 혁신법 체계에서 전문기관의 연구개발비 정산 (기관 유형에 따라 회계감사 또는 전문기관 정산)
- 연구개발비 카드·통합 시스템 사용 기준은 해당 전문기관 안내 확인
