# 사업 유형별 판단 포인트

> 탐색 지도. 유형마다 "어디서 결론이 갈리는지"를 정리했다. 결론 근거는 해당 사업 운영지침 원문이다.

## 1. R&D (국가연구개발사업)
- 적용 규범: 「국가연구개발혁신법」·시행령, 「국가연구개발사업 연구개발비 사용 기준」 등 과기정통부 고시, 부처·전문기관 관리지침
- 국고보조금 일반 원칙(보조금법)과 **체계가 다르다** → 섞어서 답하지 않는다
- 자주 묻는 것: 참여연구원 인건비 계상, 학생인건비, 연구수당 한도, 연구장비 구입 승인, 회의비 단가, 시험분석 외주, 위탁연구개발비, 간접비 사용, 연구개발비 카드
- 확인 순서: 고시 → 전문기관 사업비 관리 매뉴얼 → 협약서 특약

## 2. 교육훈련
- 강사료: 일시적이면 기타소득(필요경비 적용 여부 확인), 반복적이면 사업소득 3.3% → `40-tax-accounting.md` §2
- 강사료 단가: 사업 지침 또는 기관 강사료 기준. 공무원 강사는 별도 기준이 있을 수 있음
- 교재·인쇄비, 교육장 임차료, 수강생 식비·다과비 한도
- 수강료 수입이 있으면 사업수입 처리·면세 여부 확인
- 다른 정부 훈련지원금(예: 고용보험 사업주 훈련 지원)과 **중복 수혜** 여부 확인

## 3. 인력양성 (채용·인턴·참여인력)
- 신규 채용 요건(채용일, 기존 인력 여부), 인건비 지원 한도·기간
- 4대보험 사업주 부담분 편성 가능 여부
- 퇴직급여 충당금·연차수당 인정 여부
- 다른 정부 인건비 지원사업과 **동일인 중복 지원** 금지 여부
- 중도 퇴사 시 정산·반환

## 4. 전시회·해외마케팅
- 부스 임차료·장치비·운송비·통역비·바이어 초청비
- 해외 지출 증빙: 인보이스 + 송금증(또는 해외 카드전표), 번역
- **환율 적용 기준**: 결제일 기준, 송금일 기준, 카드 청구 기준 등 지침마다 다름
- 해외 출장 여비: 기관 여비규정, 항공권 등급 제한
- 해외 사업자에게 지급 시 부가세 대리납부·원천징수(조세조약) 이슈 가능 → "세무 전문가 확인 필요"로 표시

## 5. 일반 보조사업 (행사·운영·홍보 등)
- 운영비: 사무실 임차료·공공요금의 사업 귀속 비율 안분
- 업무추진비·식비: 사용 제한 업종, 단가, 회의록
- 홍보물·기념품: 단가 한도, 배부 대장
- 위탁·외주: 계약 절차(비교견적·입찰), 재위탁 제한
- 자산 취득: 사전 승인, 중요재산 사후관리
- 자부담: 현금·현물 구분, 현물 인정 범위

## 6. 분야명 ≠ 법적 체계
같은 "교육"·"전시" 사업도 국고보조, 지방보조, 위탁계약, 별도 지원사업 등으로 운영될 수 있다. **분야명만으로 적용 규정을 정하지 않는다.**
혼합 재원(국비+지방비+자부담)은 재원별 적용 규정, 자부담 배분, 중복지원 금지를 각각 확인한다.

| 유형 | 먼저 확인할 것 | 자주 놓치는 지점 |
|---|---|---|
| 국가R&D | 혁신법 적용 여부, 과제·단계, 기관 유형, 고시와 공고·협약 | 사용 용도, 현금·현물, 단계별 사전승인과 정산 |
| 교육훈련 | 과정의 재원, 지급 방식, 공고와 운영지침 | 강사료·교재·장소비 단가, 출석·수료 증빙, 실비/단가/성과 지급 구분 |
| 인력양성 | 주관기관과 수행자 지위, R&D 과제 포함 여부, 지원금·수당의 법적 성격 | 근로계약·참여수당·장학금 구분, 인건비 중복 계상 |
| 전시 | 해당 연도 공고, 선정 통보, 행사 기간과 비용 발생 기한 | 부스비·장치비·운송비·출장비 구분, 환율, 지원 한도, 부가세, 중복 지원 |
| 일반 보조 | 국고/지방/혼합 재원, 직접/간접보조, 전담기관·교부조건 | 전용계좌·카드, 교부 전 지출, 변경 승인, 자부담, 잔액·이자·환급금 반납 |

특정 지역·연도 공고(예: 한 지자체의 전시 참가 지원 공고)는 **그 사업에만** 적용한다. 다른 사업으로 일반화하지 않는다.
