# 국가R&D 회의비·다과·식비

## 먼저 확인할 사실
1. 회의 **날짜** (사건일) — 2026. 5. 6. 전후로 기준이 다르다
2. **참석자 구성** — 해당 과제 참여연구자만인지, 외부인·다른 기관 사람이 있는지
3. 계상 **비목** — 연구활동비(회의비)인지 연구혁신비인지
4. 금액 단위 — 1인당인지, 건당 총액인지 (부가세 포함 여부)
5. 기관 자체 기준과 사업 지침의 단가

## 분기
| 순서 | 판단 | 근거 |
|---|---|---|
| ① | **전국 공통 1인당 식비 상한은 고시에 없다.** 단가는 기관 자체 기준·사업 지침에서 찾는다 | 연구개발비 사용 기준 제25조에 1인당 금액 규정 없음 |
| ② | 다과가 "회의비 중 식비"인지는 기관 기준·과제 지침으로 확인. 확인 전에는 단정하지 않는다 | 제10조제3호(회의비 정의) |
| ③ | 2026. 5. 6. 이후 회의: 연구활동비로는 **참여연구자만 참여하는 회의**의 식비 계상 불가. 외부인이 있으면 이 금지 조항에 해당하지 않음 | [제25조제4항](../../laws/rnd-cost-standard/25.md) |
| ③' | 2026. 5. 5. 이전 회의: 식비 계상 원칙적 불가, **소속되지 않은 자가 참여하는 회의 중 사전 내부결재 완료** 회의만 가능 | [직전 판본 제25조제4항](../../laws/rnd-cost-standard/25.prev-2026-03-11.md) (2026. 3. 11.~5. 5.) |
| ④ | 연구혁신비로는 참여연구자만 참여하는 회의의 식비 계상 가능. **이 조는 부칙에 따라 2026. 6. 11.부터 시행** | [제25조의2제6항](../../laws/rnd-cost-standard/25-2.md), [부칙](../../laws/rnd-cost-standard/addenda.md) |
| ⑤ | 증빙: 내부결재문서 또는 회의록 중 하나 + 영수증서. **10만 원(부가세 포함) 이하**는 목적·일시·장소·내용·참석자 명단을 적은 증명자료로 결재문서·회의록을 대신할 수 있음 — **영수증 생략이 아니고, 1인당 한도도 아님** | [제25조제5항](../../laws/rnd-cost-standard/25.md) |
| ⑥ | 주류 등 유흥성 비용은 계상 불가 | [제21조제4항제2호](../../laws/rnd-cost-standard/21.md) |
| ⑦ | 결제는 연구비카드 또는 계좌이체 | [제22조제5항](../../laws/rnd-cost-standard/22.md) |

## 섞지 말 것
- 1인당 한도(기관 기준) / 건별 증빙 간소화 기준(10만 원) / 참석자 조건(제25조제4항)은 **서로 다른 기준**이다.
- 사건일이 2026. 3. 11. 이전이면 수록된 직전 판본도 맞지 않을 수 있다 → 원문 연혁 확인.
