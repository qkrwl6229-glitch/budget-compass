# RCMS 부가세 — 증빙 합계와 연구비 부담액

## 원칙
- 환급받을 수 있는 부가가치세는 **실제 환급받지 않았더라도** 연구개발비로 계상할 수 없다 — [연구개발비 사용 기준 제21조제4항제1호](../../laws/rnd-cost-standard/21.md)
- 공제·환급 가능 여부는 **연구개발기관의 부가세 지위**(일반과세자·면세사업자·비영리 고유목적 등)와 거래별 불공제 사유로 정해진다 — [부가가치세법 제38조](../../laws/vat-act/38.md), [제39조](../../laws/vat-act/39.md)

## 증빙 방식별 정리
| 방식 | 증빙 합계 | 공급가액 | 부가세 | 연구비 최종 부담액 |
|---|---|---|---|---|
| **정액 여비** (규정 단가로 지급) | 지급액 | — | 별도 매입세액 없음 | 지급액 전부. **10%를 임의로 빼지 않는다** |
| **실비 영수증** (숙박 등, 공급자가 과세사업자) | 카드·현금영수증 총액 | 총액 − 세액 | 영수증상 세액 | 공제 가능 → 공급가액만 / 공제 불가 → 총액 / **미확인 → 둘 다 제시하고 확정하지 않음** |
| **전자세금계산서** | 합계금액 | 공급가액 | 세액 | 공제 가능 → 공급가액만 / 불가 → 합계 |
| **카드 결제** | 승인액 | 승인액 − 세액 | 전표상 세액 | 위와 같음. 카드 승인액 ≠ 연구비 부담액일 수 있음 |

## 이미 부가세 포함으로 이체한 경우 (복원 경로 후보)
공제 가능한 부가세까지 연구비로 이체했다면, RCMS의 **부가세복원** 메뉴가 후보다. 확정 안내가 아니라 "이런 경로가 있다"로 안내하고, 해당 전문기관 안내를 확인하게 한다.

| 출처 | 내용 (자체 요약) |
|---|---|
| RCMS 매뉴얼 4.2 취소/복원내역등록 – 부가세복원 (112쪽) | 연구비 현금이 사용된 내역 중 **부가세를 RCMS로 복원**하는 메뉴. 부가세가 포함된 **이체 완료** 내역만 조회됨. 카드 내역 중 가맹점 취소 건이 있으면 연구비 취소를 먼저 처리. 가상계좌로 **요청 금액과 같은 금액**을 입금. 매뉴얼에는 취소 금액 1,000만 원 이상이면 전문기관 과제담당자 승인 후 입금 가능하다는 안내가 있음(산업부 과제 기준) |
| RCMS 매뉴얼 4.1 취소/복원 가상계좌조회 (107쪽) | 연구비 취소·부가세복원 요청으로 개설된 가상계좌 확인 |
| RCMS 매뉴얼 4.2 연구비사용취소 (108~111쪽) | RCMS로 사용된 연구비 현금을 다시 RCMS로 복원해 취소 (부분 취소 가능) |

출처: 한국산업기술기획평가원(KEIT) 「RCMS 연구개발기관 사용자 매뉴얼」 (2023. 12. 19. 작성, 2024. 5. 14. 게시, 176쪽) https://www.gaia.go.kr/download/04_01/RCMS_usr_manual.pdf
— 화면·메뉴 근거로만 쓴다. 다른 전문기관 과제는 해당 기관 안내를 확인. 메뉴명은 이후 바뀌었을 수 있다(실제 화면 미확인).

## 섞지 말 것
증빙 총액 / 연구비 부담액 / RCMS 등록 금액 / 이체 금액 / 부가세 복원은 **각각 다른 값 또는 절차**다. 사용자가 어느 것을 묻는지 먼저 정리한다.
