# 국가R&D 출장비·자가용·외부 전문가

## 먼저 확인할 사실
1. 이동하는 사람의 **지위** — 참여연구자·연구근접지원인력인지, 외부인인지
2. 공무원인지 아닌지
3. 외부인이면 **역할** — 자문·강연(전문가 활용), 단순 참석, 공동연구기관 소속
4. 출장 명령(또는 기관 내부 승인)이 있는지
5. 교통수단과 산정 방식 — 정액 운임, 실비(유류비 영수증), 거리 기준

## 분기
| 경우 | 판단 | 근거 |
|---|---|---|
| 참여연구자가 **공무원** | 「공무원 여비 규정」에 따라 계상 | [연구개발비 사용 기준 제25조제6항제1호](../../laws/rnd-cost-standard/25.md) |
| 참여연구자가 **공무원이 아님** | 기관 자체규정 또는 「공무원 여비 규정」 중 선택 | [제25조제6항제2호](../../laws/rnd-cost-standard/25.md) |
| 출장지에서 식사 제공 | 출장비에서 해당 금액 차감 | [제25조제7항](../../laws/rnd-cost-standard/25.md) |
| 공무원 여비 규정의 국내 자동차운임 | 별표 2(국내 여비 지급표)에 따름 — **별표는 이미지라 수록하지 않음, 원문 확인** | [여비 규정 제13조](../../laws/travel-regulation/13.md), [별표 목록](../../laws/travel-regulation/index.md) |
| 외부 전문가에게 자문료·강사료 | **외부 전문기술 활용비 중 전문가 활용비**가 후보 (원고료·강사료·자문료 포함) | [제10조제2호](../../laws/rnd-cost-standard/10.md) |
| 외부 전문가의 교통비 | 전문가 활용비에 교통비를 포함해 지급할 수 있는지, 기관 기준에 별도 조항이 있는지 **확인 전 미확인** | 기관 자체규정, 사업 지침 |
| 공무원이 아닌 사람을 공무로 여행시키는 경우(여비 규정 준용) | 여비 규정 제30조·별표 9 | [여비 규정 제30조](../../laws/travel-regulation/30.md) |

## 섞지 말 것
- 본인 출장과 외부 전문가 초청은 **지출 목적부터 다르다** — 비목(출장비 vs 전문가 활용비)이 갈린다.
- 유류비 실비, 거리 기준 정액, 정액 운임은 산정 방식이 다르다. 기관 기준을 확인하기 전에는 **금액을 확정하지 않는다.**
- 외부인이라는 이유만으로 전문가 활용비가 되지 않는다. 역할(자문·강연)이 있어야 후보가 된다.
- 정액 여비에는 별도 매입세액이 없다 → 정액에서 10%를 임의로 빼지 않는다 (`rcms-vat.md`).
