# 국가R&D 장비 구입

## 먼저 확인할 사실
1. 금액 — **부가세·구입·설치 등 부대비용을 포함한 총액**
2. 협약(연구개발계획)에 **반영된 장비인지**, 반영됐는데 바꾸는 것인지, 아예 없던 것인지
3. 공동활용 가능 장비인지
4. 결제 방법 — 연구비카드 / 계좌이체, 과제·은행의 1회 한도
5. 계약·납품·검수 일정이 연구개발기간 안인지

## 분기 — 하나의 금액 기준으로 합치지 않는다
| 단계 | 기준 | 근거 |
|---|---|---|
| 계획 변경 사전승인 | 원래계획에 없던 **3천만 원 이상**(부가세·부대비용 포함) 장비 신규 구입·임차, 계획 장비의 변경(환율·물가 등 불가피한 **20% 이내** 증감 제외), 계획 장비 미구입 → 중앙행정기관 **사전 승인** | [제73조제1항제5호](../../laws/rnd-cost-standard/73.md) |
| 승인 절차 | 변경 사유·내용 제출 → 보완 요구 가능 → 접수 후 15일 이내 통보 | [제74조](../../laws/rnd-cost-standard/74.md) |
| 계상 전 공동활용 확인 | 취득가격 3천만 원 이상(또는 미만이라도 공동활용 가능) → ZEUS 등록 장비의 공동활용 여부 확인 후 계상 | [제23조제4항](../../laws/rnd-cost-standard/23.md) |
| 1억 원 이상 | 시설·장비 표준지침에 따라 비용 사용 | [제23조제3항](../../laws/rnd-cost-standard/23.md) |
| 도입 심의 | 국가연구시설장비심의위원회 심의 대상: 총 구축비 **3억 원 이상** 등 | [표준지침 제18조](../../laws/rnd-facility-standard/18.md) |
| 등록 | 3천만 원 이상(또는 공동활용 가능) 장비는 자산등재 후 **30일 이내 ZEUS 등록** | [표준지침 제28조](../../laws/rnd-facility-standard/28.md) |
| 결제 | 연구비카드 또는 계좌이체 | [제22조제5항](../../laws/rnd-cost-standard/22.md) |
| RCMS 등록 화면 | 사용 등록 중 연구장비 등록: 3천만 원 미만 i-Tube, ZEUS 등록 장비 조회 | RCMS 매뉴얼 3.1 연구장비등록 (71~81쪽) — `rcms-transfers.md` 출처 참고 |

## 섞지 말 것
- **3천만 원은 "1회 이체 한도"가 아니다.** 사전승인·공동활용 확인·ZEUS 등록의 기준이다. 실제 결제 한도는 과제·은행·RCMS 설정이라 확인하지 못하면 미확인으로 답한다.
- 사전승인(제73조), 도입 심의(표준지침 제18조), ZEUS 등록(제28조), 기관 계약 절차는 **각각 별개 단계**다.
- 2,999만 원과 3,000만 원은 부가세·부대비용을 포함한 총액으로 비교한다.
