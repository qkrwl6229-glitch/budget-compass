# 원천징수 — 강사비·자문료·원고료·일용

## 먼저 나눌 것 (이 순서대로)
1. 받는 사람: **개인 / 법인** — 법인이면 이 표 대상 아님(세금계산서 등 별도)
2. **거주자 / 비거주자** — 비거주자는 국내원천소득·조세조약 별도 검토, 전문가 확인 권고
3. **고용관계** 여부 — 있으면 근로소득(간이세액표) 또는 일용근로
4. **계속·반복성** — 반복적 독립 용역이면 사업소득, 일시적이면 기타소득 후보
5. **세전 / 세후 약정** — 세후면 역산 필요
6. **지급일** — 적용 판본 결정

`calc.py` 는 소득 분류나 필요경비율을 **결정하지 않는다.** 분류가 미상이면 시나리오별 결과만 보여준다.

## 기준
| 소득 | 원천징수 | 근거 |
|---|---|---|
| 원천징수대상 사업소득 | 지급액 × 3% + 지방소득세(소득세의 10%) | [소득세법 제129조](../../laws/income-tax-act/129.md), [지방세법 제103조의13](../../laws/local-tax-act/103-13.md) |
| 거주자 인적용역 사업소득 소액부징수 | 2024. 7. 1. 이후 지급분은 1,000원 미만이어도 징수 | [소득세법 제86조](../../laws/income-tax-act/86.md), 국세청 원천징수 안내 |
| 기타소득 | (지급액 − 필요경비) × 20% + 지방소득세. 필요경비 60% 의제는 **해당 유형에만** | [제21조](../../laws/income-tax-act/21.md), [제129조](../../laws/income-tax-act/129.md), [시행령 제87조](../../laws/income-tax-decree/87.md) |
| 기타소득 과세최저한 | 건별 기타소득금액이 기준 이하이면 과세 안 함 | [제84조](../../laws/income-tax-act/84.md) |
| 일용근로 | (일급 − 근로소득공제) × 6% − 세액공제. 소액부징수 1,000원 미만 (한꺼번에 지급하면 소득자별 합계로 판단) | [제129조](../../laws/income-tax-act/129.md), [제86조](../../laws/income-tax-act/86.md) |
| 지급명세서 | 원천징수 여부와 관계없이 제출 의무 확인 | [제164조](../../laws/income-tax-act/164.md) |

## 계산 (`scripts/calc.py`)
- 세전 300만 원: 기타소득(60%) 264,000원 / 사업소득 99,000원 — 전제(거주자 개인, 세전)를 표 위에 적는다
- 세후 약정: `calc.py gross-up` 이 최소 세전액을 찾아 재검산한다
- 실행할 수 없으면 산식을 적고 손으로 검산하며, 실행했다고 쓰지 않는다

## 섞지 말 것
- 지급 적격성(이 강사비를 사업비로 써도 되나, 단가·승인)과 세액 계산은 **별개 질문**이다.
- 국세 / 지방소득세 / 실지급액 / 사업비 인정액을 각각 적는다.
