# RCMS 이체 경로 — 거래처·기관 계좌·원천징수계좌·자계좌

## 원칙
- 직접비는 **연구비카드**(발급 전 법인명의 카드 포함) 또는 **계좌이체**로 사용. 외국 물품 수입 등 불가피한 경우만 현금 — [연구개발비 사용 기준 제22조제5항](../../laws/rnd-cost-standard/22.md)
- "거래처에 직접 이체"는 **계좌이체를 선택한 경우**의 원칙이다. 카드 결제와 섞지 않는다.

## 경로 구분
| 경로 | 언제 | RCMS 매뉴얼 (자체 요약) |
|---|---|---|
| 카드 | 연구비카드 결제 후 사용 등록 | 3.1 증빙 우선 등록(카드) 36~39쪽, 비목 우선 등록(카드) 57~60쪽 |
| 거래처 직접 이체 | 세금계산서·현금영수증 등 증빙으로 등록 후 이체 실행 | 3.1 증빙 우선 등록(전자세금계산서) 30~35쪽 → 3.2 연구비 이체 실행 93~96쪽 |
| 인건비 직접 지급·원천징수계좌 | RCMS에서 연구원 개인에게 인건비를 직접 이체, 원천징수 입력 방식에 따라 지급액 입력, 원천징수 계좌 등록 | 3.1 인건비 직접지급 등록 86~90쪽 |
| 자계좌(기관 계좌) 이체 | **허용 세부항목**이면 그대로, 허용 항목이 아니지만 특별한 사유가 있으면 **전문기관 승인** 후 | 3.4 자계좌이체 승인 요청 100~101쪽 |

## 자계좌이체 — 세 갈래
| 갈래 | 확인할 것 | 근거가 없으면 |
|---|---|---|
| 허용 비목·세부항목 | 해당 전문기관·사업의 현재 허용 목록 | **미확인**. 예전 안내의 사례(인건비·연구수당·여비 등)를 현재 전체 목록처럼 말하지 않는다. 예시를 들 때는 출처의 기관·연도를 밝힌다 |
| 허용 상황 | 특별한 사유가 있는지 | 사유를 기관에 질의 |
| 전문기관 승인 | 매뉴얼상 절차: 연구개발기관이 자계좌이체 사용 요청 공문을 전문기관에 제출(사전 업무 협의) → 받은 **승인 공문을 첨부**해 RCMS에서 승인 요청. 요청 상태에서만 취소 가능 | 승인 전 이체를 전제로 안내하지 않는다 |

## 하지 않는 것
- RCMS에 로그인하거나, 실제 이체·승인을 실행하거나, 실행했다고 말하지 않는다.
- 과제 접근 없이 **현재 허용 목록·이체 한도를 확정하지 않는다** → "공개 매뉴얼 기준 기능은 이렇고, 이 과제에서 허용되는지는 전문기관 확인 필요".
