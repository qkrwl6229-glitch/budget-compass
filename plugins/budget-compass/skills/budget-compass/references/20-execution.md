# 사업비 집행

> 탐색 지도. 조문 번호는 law.go.kr 현행 원문으로 다시 확인한 뒤 인용한다.

## 1. 관련 규범 (국고보조금)
| 규범 | 주요 내용 | 비고 |
|---|---|---|
| 「보조금 관리에 관한 법률」 | 용도 외 사용 금지(제22조), 보조금 교부결정 취소·반환, 제재부가금, 중요재산 처분 제한 등 | 제22조 외 조문 번호는 `[조문 확인 필요]` |
| 같은 법 시행령 | 세부 절차, 중요재산 범위 등 | |
| 기재부 연도별 「예산 및 기금운용계획 집행지침」 | 보조금 집행 일반 원칙 | 연도 확인 |
| 「국고보조금 통합관리지침」(기획재정부) | e나라도움 사용, 집행·정산 절차 | 현행 여부 확인 |
| 개별 사업 운영지침·협약서 | 비목별 집행 기준, 변경 승인 절차 | **최우선** |

지방보조금은 「지방자치단체 보조금 관리에 관한 법률」과 해당 지자체 조례·운영기준을 따른다.
국가R&D는 「국가연구개발혁신법」 체계를 따르며, 아래 국고보조금 원칙을 그대로 적용하지 않는다.

## 2. 쟁점별 일반 원칙
| 쟁점 | 일반 원칙 | 결론이 자주 갈리는 지점 |
|---|---|---|
| **사업기간 전 집행 / 선집행** | 협약(교부결정) 전·사업기간 외 지출은 불인정이 원칙 | 지침이 협약 전 자부담 선집행 후 정산을 허용하는지, 소급 인정 조항 |
| **교부 전 자금 부족** | 자부담으로 선지급 후 보조금으로 보전하는 방식은 지침 허용 시에만 | 전용계좌 이체 규정, 보전 가능 기간 |
| **비목 간 변경(전용)** | 일정 비율 이내는 자체 변경, 초과·신규 비목은 사전 승인이 흔함 | 변경 허용 비율, 승인권자, 승인 전 집행 여부 |
| **사업내용 변경** | 중요 내용 변경은 사전 승인 | 무엇이 "중요 변경"인지 지침 정의 |
| **결제 수단** | 보조금 전용카드·전용계좌, e나라도움 실시간 이체가 원칙 | 현금 지급 예외, 해외 결제 |
| **분할 결제·쪼개기** | 계약 기준 회피 목적 분할은 금지 | 수의계약 한도, 견적 기준 |
| **계약** | 일정 금액 이상은 경쟁입찰·비교견적 | 국가계약법 준용 여부, 지침상 금액 기준 |
| **자산 취득** | 사전 승인, 취득 후 중요재산 관리·처분 제한 | 금액 기준, 사후관리 기간 |
| **이자** | 보조금 발생 이자는 반납 또는 사업비 사용 여부가 지침에 따라 다름 | 지침 명시 |
| **집행 잔액** | 정산 후 반납 | 반납 시기·방법 |

## 3. 판단 흐름
```
지출 시점이 사업기간·협약기간 안인가? ── 아니오 → 불가(소급 인정 조항 있으면 조건부)
          │ 예
편성된 비목·세목에 해당하는가? ── 아니오 → 변경 승인 받으면 조건부 가능
          │ 예
지침상 제한 항목(사용 제한 업종·한도)에 걸리는가? ── 예 → 불가 또는 한도 내 조건부
          │ 아니오
결제수단·계약절차·증빙을 지켰는가? ── 아니오 → 정산 시 불인정 위험
          │ 예
        가능 (단, 개별 지침 확인 전제)
```
