# 국가R&D 연구개발비 · RCMS 집행

> 국가연구개발혁신법 적용 과제의 연구개발비 집행 질문용. 아래 ✅ 조문은 2026. 11. 12. 국가법령정보센터 원문에서 확인한 **제작 시 검증 이력**이다.
> 답변할 때는 사건일 적용판을 다시 확인한다. 같은 고시도 개정 전후(예: 2026. 5. 6. 시행) 내용이 다를 수 있다.

## 1. 근거의 종류를 섞지 않는다
| 근거 | 무엇을 증명하나 | 무엇을 증명하지 못하나 |
|---|---|---|
| 「국가연구개발사업 연구개발비 사용 기준」(과학기술정보통신부고시) | 모든 혁신법 과제에 공통인 계상·사용·인정 기준 | 개별 과제의 승인 내용, 기관 자체 기준 |
| 부처·전문기관 관리지침, 협약서 | 그 과제에 허용되는 행위 | 시스템 화면·기능 |
| RCMS 등 연구비 관리시스템 매뉴얼 | 시스템에 있는 기능·화면 (매뉴얼 날짜 기준) | **그 과제에서 그 집행이 허용되는지** |
| 기관 자체 규정 (여비·회의비·자가용 운임 등) | 기관 내부 단가·산식 | 다른 기관에 대한 기준 |

- 사용자가 과제 시스템에 직접 접속해 보여준 것이 아니면 "등록 가능/이체 가능을 확인했다"고 쓰지 않는다.
- 메뉴명·화면 경로는 매뉴얼 날짜를 적거나 "실제 화면 미확인"으로 표시한다. 오래된 가이드의 목록(예: 자계좌이체 허용 사례)은 **연도·적용 사업과 함께 예시로만** 쓴다.

## 2. 확인한 공통 기준 (과학기술정보통신부고시 제2026-38호, 2026. 5. 6. 시행)
| 쟁점 | 조문 | 내용 요지 | 상태 |
|---|---|---|---|
| 부가세 | 제21조제4항제1호 | 환급받을 수 있는 관세·부가가치세 등은 **실제 환급받지 않았더라도** 연구개발비로 계상할 수 없음 | ✅ |
| 유흥성 비용·중복계상 | 제21조제4항제2호·제3호 | 주류 등 유흥성 비용, 같은 비용의 2회 이상·현금/현물·직접비/간접비 중복계상 금지 | ✅ |
| 결제 수단 | 제22조제5항 | 직접비는 연구비카드(발급 전 법인명의 카드 포함) 또는 계좌이체로 사용. 외국 물품 수입 등 불가피한 경우만 현금 | ✅ |
| 장비 1억 원 이상 | 제23조제3항 | 부가세·부대비용 포함 1억 원 이상 장비 구입은 「국가연구개발 시설ㆍ장비의 관리 등에 관한 표준지침」에 따름 | ✅ |
| 장비 3천만 원 이상 | 제23조제4항 | 취득가격 3천만 원 이상(부가세·부대비용 포함) 또는 공동활용 가능 장비는 ZEUS 공동활용 여부 확인 후 계상 | ✅ |
| 장비 계획 변경 | 제73조제1항제5호 | 원래계획에 없던 3천만 원 이상 장비 신규 구입·임차, 계획 장비의 변경(환율·물가 등 불가피한 20% 이내 증감 제외), 미구입 등은 **중앙행정기관 사전 승인** | ✅ |
| 회의비 식비 | 제25조제4항 | 해당 과제 **참여연구자만** 참여하는 회의는 회의비 중 식비를 계상할 수 없음 | ✅ |
| 〃 예외 | 제25조의2제6항 | **연구혁신비**로는 참여연구자만 참여하는 회의의 식비를 계상할 수 있음 | ✅ |
| 회의비 증빙 | 제25조제5항 | 내부결재문서 또는 회의록 중 하나 + 영수증서. **10만 원(부가세 포함) 이하**는 목적·일시·장소·내용·참석자 명단을 적은 증명자료로 결재문서·회의록을 대신 가능 | ✅ |
| 연구수당 | 제26조제1항 | 수정인건비(인건비+학생인건비 등)의 20% 범위 | ✅ |
| 사전 승인 대상 전체 | 제73조 | 총액·연도별 정부지원금/기관부담금 변경, 간접비 총액 증액, 위탁연구개발비 20% 이상 증액 등 | ✅ |
| 시설·장비 표준지침 | — | 「국가연구개발 시설ㆍ장비의 관리 등에 관한 표준지침」 과학기술정보통신부고시 제2026-59호, 2026. 9. 30. 시행 | ✅ |

> 10만 원 기준은 **증빙 간소화 기준**이다. 1인당 식비 상한이나 사용 허용 한도가 아니다. 1인당 단가는 기관 자체 기준·과제 지침에서 따로 찾는다.

## 3. 자주 묻는 R&D 집행 질문 — 분기 순서
| 질문 | 먼저 나눌 것 | 근거 없으면 |
|---|---|---|
| 회의비·다과·식비 | ① 전국 공통 1인당 한도가 있는지(없으면 그렇다고 말함) → ② 다과가 식비인지 → ③ 참석자 구성(참여연구자만/외부인 포함) → ④ 비목(연구활동비/연구혁신비) → ⑤ 기관·과제 단가 → ⑥ 증빙(10만 원 간소화) | 허용액은 보류, 원칙만 |
| 장비 구입 | ① 결제 채널 한도(카드·이체) → ② 협약·계획 반영 여부 → ③ 변경 사전승인(제73조) → ④ ZEUS 확인·도입 심의(3천만/1억) → ⑤ 계약·납품·검수 기한 | 3천만 원을 "1회 이체 한도"로 답하지 않는다. 과제·은행 한도는 미확인 표시 |
| 부가세 포함 등록 | ① 정액 지급인지 실제 거래인지 → ② 공제·환급 가능성 → ③ 증빙 총액·공급가액·세액과 **연구비 부담액**을 나란히 | 정액 여비에서 10%를 임의로 빼지 않는다 (정액 지급금에는 매입세액이 없음) |
| 출장·유류비 | ① 출장자가 참여연구자이고 출장 명령이 있는지 → ② 외부인이면 역할(자문·강연·단순 참석·공동기관 소속) → ③ 기관 자가용 운임 산식 | 외부인 교통비를 무조건 출장비로 등록하라고 하지 않는다. 자문이면 전문가활용비를 **후보**로만 |
| 자계좌·이체 경로 | 카드 / 거래처 직접 이체 / 기관 계좌 이체 / 원천징수 계좌를 각각 구분 | "거래처 직접 이체 원칙"은 계좌이체를 선택한 경우로 한정. 현재 과제의 허용 목록은 미확인 표시 |
| 강사비·자문료 | 지급 적격성(비목·단가·승인)과 원천징수 계산은 **별개** | `40-tax-accounting.md` §2, `calc.py` |
| 할인·환불 | `40-tax-accounting.md` §7 (에누리 분기) | — |
